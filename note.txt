--- DAY 3 ---

6. step pengerjaan
  - buat folder middleware dan file authMiddleware
  - buat route yg akan di proteksi
  - update server.js (bagian route)

7. cara pakai middleware
  - per route 
  // routes/taskRoutes.js
const express = require('express');
const authMiddleware = require('../middleware/authMiddleware');
const { getAllTasks } = require('../controllers/taskController');

const router = express.Router();

// Proteksi semua route di file ini
router.use(authMiddleware);  // ← Semua route di bawah ini wajib login

router.get('/', getAllTasks);

module.exports = router;

  - per endpoint
// Hanya endpoint tertentu yang diproteksi
router.get('/', authMiddleware, getAllTasks);  // Wajib login
router.get('/public', getPublicTasks);         // Bebas diakses

  - lalu di server utuk semua route yg akan di proteksi
// Proteksi semua route /api/tasks
app.use('/api/tasks', authMiddleware, taskRoutes);

8. flow

Client → server.js → routes → middleware → 401 "Token tidak ditemukan"

DENGAN TOKEN VALID:
Client → server.js → routes → middleware → verify OK → controller → response

                                          └── req.user = { userId: 1 }
